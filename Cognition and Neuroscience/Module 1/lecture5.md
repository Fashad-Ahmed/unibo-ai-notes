## 1. Learning, memory, and neural plasticity

### Learning

**Learning** is the process through which experience produces an enduring change in knowledge or behavior.

### Memory

**Memory** is the result of learning and involves three main processes:

1. **Encoding** – converting incoming information into a memory trace.
2. **Storage** – maintaining that information over time.
3. **Retrieval** – accessing stored information for conscious recall or to guide behavior.

Encoding itself includes:

* **acquisition**: information enters short-term memory;
* **consolidation**: the memory becomes progressively stabilized into a long-term form.

### Neural plasticity

**Neural plasticity** is the capacity of neural connections to change as a result of experience.

The central idea of the lecture is:

> Learning results from changes in the strength of synaptic interactions among neurons in neural networks.

Plasticity may be:

| Short-term plasticity                            | Long-term plasticity                                    |
| ------------------------------------------------ | ------------------------------------------------------- |
| Lasts seconds to hours                           | Lasts days, years, or longer                            |
| Functional or physiological                      | Includes structural and anatomical change               |
| Alters existing synaptic effectiveness           | May involve new synapses, enlarged synapses, or pruning |
| Often involves temporary protein phosphorylation | Often requires gene transcription and protein synthesis |

Structural plasticity continues throughout life, although much developmental change involves the selective pruning of existing connections.

# 2. Multiple memory systems

Memory is not one unitary ability. Different forms of memory depend on different neural systems.

## Long-term memory

### Explicit or declarative memory

Explicit memory involves conscious recollection.

It includes:

* **episodic memory**: memory for personal events and experiences;
* **semantic memory**: memory for facts, concepts, and general knowledge.

It depends strongly on the:

* hippocampus;
* medial temporal lobe;
* association cortex.

### Implicit or non-declarative memory

Implicit memory is expressed through performance without requiring conscious recollection.

It includes:

* procedural skills and habits;
* priming;
* Pavlovian and instrumental conditioning;
* habituation and sensitization.

Different implicit forms depend on different structures:

| Type                           | Main neural system |
| ------------------------------ | ------------------ |
| Procedural skills and habits   | Striatum           |
| Priming                        | Neocortex          |
| Emotional conditioning         | Amygdala           |
| Skeletal conditioned responses | Cerebellum         |
| Habituation and sensitization  | Reflex pathways    |

This organization shows that distinct memories can be learned and expressed independently.

# 3. Patient H.M. and the existence of multiple memory systems

## Background

Patient H.M., later identified as Henry Molaison, underwent bilateral surgery to treat severe epilepsy.

The operation removed substantial portions of the medial temporal lobes, including much of the hippocampal formation and nearby tissue.

## Main impairment

After surgery, H.M. developed severe **anterograde amnesia**:

* he could not form normal new long-term declarative memories;
* he could meet someone repeatedly but fail to remember them;
* he could not retain new facts or events after attention shifted.

## Preserved abilities

H.M. retained:

* relatively normal intelligence;
* language;
* perception;
* short-term or working memory;
* many memories formed long before surgery;
* procedural learning.

For example, he improved on mirror-drawing tasks over repeated practice, although he did not consciously remember performing the task before.

## Conclusions from H.M.

H.M. demonstrated that:

1. memory is partly separable from intelligence and perception;
2. short-term and long-term memory depend on different mechanisms;
3. explicit and implicit memory are separate systems;
4. the medial temporal lobe is essential for forming new declarative memories;
5. the hippocampus is not required for all learning or all long-term memory;
6. procedural skills can be acquired without conscious recollection.

His impairment therefore provides a **dissociation** between declarative memory and procedural learning.  

### Important qualification

The hippocampus is not simply a permanent storage container for every memory. It is especially important for:

* encoding new declarative information;
* binding elements of an experience together;
* consolidating memories through interactions with cortical regions.

Long-established knowledge becomes increasingly dependent on distributed cortical networks.

# 4. The lesion method

The **lesion method** examines how damage to a brain region changes behavior.

Lesions may be:

* naturally occurring, such as stroke or tumor;
* surgically produced for treatment;
* experimentally produced in animals.

Lesions provide causal evidence that a structure is **necessary** for a particular function.

However, they do not prove that:

* the region works alone;
* the region is sufficient for the function;
* the damaged area performed only one function.

Lesions may also affect connected areas and cause neural reorganization.

# 5. Aplysia as a model of learning and memory

## Why use Aplysia?

**Aplysia californica** is a marine mollusk used to study cellular mechanisms of learning.

It is useful because it has:

* a relatively simple nervous system;
* large neurons;
* individually identifiable cells;
* accessible synapses;
* well-described reflex circuits.

This allowed researchers to connect a behavioral change to specific neurons, synapses, and molecular mechanisms.

---

# 6. The withdrawal reflex circuit

A light touch to the siphon activates sensory neurons.

These sensory neurons excite:

* interneurons;
* motor neurons.

Motor-neuron activity contracts the siphon and gill, producing withdrawal.

The simplified circuit is:

**touch → sensory neuron → motor neuron → withdrawal**

Interneurons provide additional excitatory, inhibitory, and modulatory pathways.

This circuit can be modified through:

* habituation;
* sensitization;
* Pavlovian conditioning.

---

# 7. Habituation in Aplysia

**Habituation** is a reduced response to a repeatedly presented harmless stimulus.

Repeated gentle siphon stimulation causes progressively weaker withdrawal.

The main mechanism is **homosynaptic depression**:

* the sensory neuron releases less neurotransmitter;
* the motor neuron receives a smaller EPSP;
* the withdrawal response becomes weaker.

This shows that simple learning can result from a change in synaptic strength rather than fatigue in the muscle or sensory receptor.

---

# 8. Sensitization in Aplysia

**Sensitization** is an increased response after a strong or harmful stimulus.

For example, a strong tail shock causes a later mild siphon touch to produce an enhanced withdrawal.

## Short-term sensitization

A strong stimulus activates facilitatory interneurons that release **serotonin** onto the sensory-neuron terminal.

Serotonin activates intracellular second-messenger pathways, including:

* cyclic AMP;
* protein kinase A;
* protein kinase C.

These temporarily alter ion channels and transmitter-release machinery.

Consequences include:

* a broader action potential;
* greater calcium entry;
* increased neurotransmitter release;
* a larger EPSP in the motor neuron;
* a stronger withdrawal response.

Short-term sensitization mainly relies on modifying proteins that already exist. 

## Long-term sensitization

Repeated training produces a response that lasts days or longer.

It shares early serotonin and cAMP mechanisms with short-term sensitization but additionally requires:

* activation of transcription factors;
* gene transcription;
* new protein synthesis;
* structural synaptic change.

Repeated serotonin signaling causes PKA and MAPK pathways to affect the nucleus.

A major transcription factor is **CREB**:

* CREB1 promotes transcription;
* inhibition by CREB2 is reduced;
* new proteins are produced;
* new synaptic terminals may grow.

The distinction is therefore:

* short-term memory modifies existing synapses;
* long-term memory changes gene expression and synaptic structure.

# 9. Pavlovian conditioning in Aplysia

Aplysia can also learn an association between two stimuli.

A typical arrangement is:

* **conditioned stimulus:** weak touch to the siphon;
* **unconditioned stimulus:** strong tail shock;
* **unconditioned response:** strong defensive withdrawal;
* **conditioned response:** enhanced withdrawal to the siphon touch alone.

Before conditioning, the weak touch produces only a small response.

When touch is repeatedly followed by shock, the touch pathway is active immediately before the modulatory shock pathway.

After conditioning, the same weak touch produces stronger transmitter release and a larger withdrawal.

# 10. Hebbian plasticity

Hebb proposed that when a presynaptic neuron repeatedly contributes to firing a postsynaptic neuron, their connection becomes stronger.

This is commonly summarized as:

> Cells that fire together wire together.

## Main requirements

### Activity dependence

The relevant synapse must be active.

A completely inactive pathway is not strengthened simply because another stimulus occurs.

### Associativity

A weak input can be strengthened when paired with a strong input.

### Temporal specificity

The weak conditioned input must occur shortly before or close in time to the strong unconditioned input.

Timing matters because the biological mechanisms activated by the two signals must overlap.

### Input specificity

Strengthening is greatest at the synapses active during learning, rather than at every synapse on the neuron.

## Aplysia and Hebbian-like learning

During conditioning:

1. the CS activates the sensory neuron;
2. calcium enters its terminal;
3. the US activates serotonin-releasing facilitatory neurons;
4. the calcium signal and serotonin pathway interact;
5. transmitter release is enhanced more than with either stimulus alone.

This is called **activity-dependent presynaptic facilitation**.

The synapse active just before the reinforcing stimulus receives the greatest strengthening. Thus, the cellular mechanism explains why correct CS–US timing is essential.

# 11. Mammalian aversive conditioning

In mammalian fear conditioning:

* a neutral stimulus, such as a tone, serves as the CS;
* an aversive event, such as shock, serves as the US;
* the animal develops a conditioned response, such as freezing, autonomic arousal, or increased startle.

The **lateral amygdala** receives information about both the CS and US.

Through learning, synapses carrying CS information become stronger, allowing the CS alone to activate fear-output pathways.

The central amygdala projects to:

* hypothalamic regions controlling autonomic responses;
* brainstem regions controlling freezing and startle;
* other systems involved in hormonal and behavioral defense.

Thus:

**CS and US converge in the amygdala → synaptic strengthening → CS later activates fear responses**

---

# 12. Hebbian-like plasticity in the amygdala

Fear conditioning has properties similar to Hebbian plasticity:

* auditory or sensory CS pathways must be active;
* aversive US pathways provide strong reinforcement;
* the signals must occur close together;
* synapses transmitting the CS are strengthened.

Important mechanisms include:

* NMDA-receptor activation;
* calcium entry;
* intracellular kinase pathways;
* AMPA-receptor changes;
* protein synthesis for long-term memory.

Fear conditioning can therefore be understood as long-term potentiation-like strengthening within amygdala circuits.

The amygdala is not merely active during fear. Its plasticity is required for learning and expressing conditioned emotional responses.

# 13. Pavlovian conditioning in humans

Human aversive conditioning often pairs:

* a neutral picture, shape, face, or sound as the CS;
* a loud noise, mild shock, or other unpleasant stimulus as the US.

Learning can be measured through the **skin conductance response**, or SCR.

## Skin conductance response

SCR reflects changes in sweat-gland activity controlled by the sympathetic nervous system.

During acquisition:

* the CS initially produces little SCR;
* after repeated CS–US pairings, the CS produces an increased SCR;
* this indicates learned anticipatory autonomic arousal.

SCR is an implicit measure because it does not require the participant to verbally report the association.

Amygdala activity correlates closely with the magnitude of conditioned SCRs.

# 14. Amygdala versus hippocampus in conditioning

A major study compared patients with selective damage to:

* the amygdala;
* the hippocampus;
* both structures;
* healthy controls.

Researchers measured:

1. conditioned SCR;
2. verbal knowledge of the CS–US relationship.

## Amygdala lesion

The patient:

* did not develop a normal conditioned SCR;
* could verbally describe which stimulus predicted the unpleasant event.

Interpretation:

* implicit emotional conditioning was impaired;
* explicit knowledge remained intact.

## Hippocampal lesion

The patient:

* developed a conditioned SCR;
* could not explicitly report the CS–US relationship.

Interpretation:

* implicit fear learning remained;
* declarative knowledge was impaired.

## Combined lesion

The patient showed impairment in both:

* conditioned autonomic response;
* declarative knowledge.

## Double dissociation

This is a **double dissociation**:

* amygdala damage impairs implicit conditioning but spares explicit knowledge;
* hippocampal damage impairs explicit knowledge but spares implicit conditioning.

This provides strong evidence for multiple memory systems.

The amygdala is necessary for the physiological expression of conditioned fear, whereas the hippocampus is necessary for conscious declarative knowledge of the association.

# 15. High-yield comparisons

## Learning versus memory

| Learning                           | Memory                                         |
| ---------------------------------- | ---------------------------------------------- |
| Acquisition of new information     | Result of learning                             |
| Produces change through experience | Encoding, storage, and retrieval               |
| Process                            | Maintained representation or behavioral effect |

## Explicit versus implicit memory

| Explicit             | Implicit                                         |
| -------------------- | ------------------------------------------------ |
| Conscious            | Often unconscious                                |
| Facts and events     | Skills, priming, conditioning                    |
| Flexible use         | Often tied to learned conditions                 |
| Medial temporal lobe | Several systems, including striatum and amygdala |

## Short-term versus long-term plasticity

| Short-term                 | Long-term                           |
| -------------------------- | ----------------------------------- |
| Seconds to hours           | Days or longer                      |
| Existing proteins modified | New proteins synthesized            |
| Functional changes         | Functional and structural changes   |
| Often phosphorylation      | Gene transcription, growth, pruning |

## Amygdala versus hippocampus

| Amygdala                    | Hippocampus                               |
| --------------------------- | ----------------------------------------- |
| Implicit emotional response | Explicit relational/declarative knowledge |
| Conditioned SCR             | Verbal awareness of CS–US relation        |
| Expression of fear learning | Conscious memory of association           |

# 16. Core exam conclusions

* Learning depends on experience-driven changes in synaptic strength.
* Memory consists of multiple systems rather than one general faculty.
* H.M. demonstrated that the medial temporal lobes are essential for new declarative memory but not all learning.
* Aplysia showed how learning can be explained at the level of identifiable cells and synapses.
* Short-term plasticity modifies existing proteins and synapses.
* Long-term memory requires gene expression, protein synthesis, and structural change.
* Hebbian plasticity explains how coincident activity selectively strengthens relevant connections.
* The amygdala supports implicit emotional conditioning.
* The hippocampus supports explicit knowledge of learned relationships.
* Their lesion effects form a double dissociation and provide causal evidence for separate memory systems.
